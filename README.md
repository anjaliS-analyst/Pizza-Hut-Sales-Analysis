# Pizza Hut Sales Analysis

# Project Overview

Pizza Hut Sales Analysis is a data analysis project focused on understanding
revenue trends, customer ordering patterns, product performance and pizza demand.

The project transforms raw sales data into meaningful business insights
through data analysis and visualization.

# Objectives

- Analyze overall pizza sales performance
- Identify best-selling and lowest-selling pizzas
- Analyze revenue generated by each pizza
- Understand pizza category performance
- Analyze pizza size preferences
- Identify ordering patterns by hour and date
- Analyze revenue contribution of pizza types
- Track cumulative revenue over time

# Category Analysis
- Quantity sold by pizza category
- Category-wise pizza distribution

# Customer Ordering Patterns
- Most common pizza size ordered
- Distribution of orders by hour
- Average number of pizzas ordered per day

# Revenue Analysis
- Percentage contribution of each pizza type to total revenue
- Cumulative revenue generated over time

# Business Insights

The analysis provides a clear view of:
